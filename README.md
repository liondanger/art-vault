# Art Vault

A visual browser for Pokémon TCG **Special Illustration Rares, Illustration Rares and full-art cards** (Mega Evolution, Scarlet & Violet, and optionally Sword & Shield).

- Filter by rarity, card type (Pokémon / Trainer / Energy), era, set and artist, or search by name
- Tap a card for high-res art, TCGplayer/Cardmarket market prices, and links to TCGplayer, GameNerdz and eBay
- ♥ Wishlist and ✓ Have lists (saved in your browser), with a copyable shopping list

Live at https://liondanger.github.io/art-vault/

Card data, images and prices come from the free [TCGdex API](https://tcgdex.dev). Single static `index.html`, no build step.
